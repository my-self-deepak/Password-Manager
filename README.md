# 🔐 Password Manager

A console-based Password Manager built with **Python** using **Object-Oriented Programming (OOP)**.

This project allows users to securely manage website passwords through a master password, save password data using JSON, generate random passwords, and perform basic password management operations.

---

## 🚀 Features

- 🔐 Master Password Authentication
- 🔑 Master Password Hashing using PBKDF2-HMAC
- 🧂 Random Salt Generation
- ➕ Add Website Password
- 👀 View Saved Passwords
- 🔍 Search Password
- ✏️ Update Password
- 🗑️ Delete Password
- 🎲 Generate Random Password
- 💾 JSON File Storage
- ⚠️ Input Validation
- ❌ Error Handling
- 🛡️ Prevent Duplicate Websites

---

## 🛠️ Technologies Used

- **Python**
- **OOP (Object-Oriented Programming)**
- **JSON**
- **Hashlib**
- **Secrets**
- **String**
